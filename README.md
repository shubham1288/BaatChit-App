# BaatChit App 💬

BaatChit is a simple group chat application where users can create groups, send messages, reply to messages, delete messages, and react using basic emojis.
The project is built using **Python**, **FastAPI**, **HTML**, **CSS**, and **JavaScript**.



---

# ✨ Features

- 💬 Send and receive messages
- 👥 Create group chats
- ↩️ Reply to messages
- 🗑️ Delete messages
- 😀 React to messages with basic emojis
- ⚡ Simple and clean user interface
- 🚀 FastAPI backend

---

## Frontend
